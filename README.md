# 🤖 CYBER-X: Cyborg-Themed Landing Page

## 📌 Project Overview

CYBER-X is a futuristic, responsive landing page designed around a cybernetic and artificial intelligence theme. The project showcases modern UI/UX principles, interactive animations, and a visually appealing cyberpunk-inspired design.

The landing page highlights the concept of human-machine integration through advanced AI technologies, neural connectivity, and cybernetic enhancements.

---

## 🚀 Features

* Responsive design for desktop, tablet, and mobile devices
* Futuristic cyberpunk-inspired user interface
* Glassmorphism design elements
* Animated typing effect
* Smooth scrolling navigation
* Interactive feature cards
* Hover animations and neon glow effects
* Contact form with user interaction
* Modern typography using Google Fonts
* Clean and maintainable code structure

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Google Fonts
